# 📊 Business 360 Dashboard | Power BI

## Project Overview

Business 360 is an end-to-end Business Intelligence dashboard developed using Power BI for AtliQ Hardware.

The dashboard enables stakeholders to analyze Finance, Sales, Marketing, Supply Chain and Executive KPIs through interactive visualizations.
